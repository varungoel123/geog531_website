Instructor guide

This pack is designed for an approximately 70-minute introductory lecture. All examples are fictional. Students need R with tidyverse and infer installed. Nothing needs printing. Assign each student a different seat number, 1 through class size, and have them replace the setup value before running the lab. Each student generates one sample, one shuffle, and one bootstrap resample, and contributes one statistic to the board at each stage. For a large class, use a few designated students to place dots after everyone records a result, or collect results electronically.

For 50 minutes, use only the one-simulation blocks, show the prepared figures for bulk results, and assign the worksheet and optional coverage investigation after class. For a longer class, let students run all code and discuss the prediction questions. Notes on every slide give facilitation prompts and correct interpretations.

Keeping the class engaged without cards

  1. Assign distinct seat numbers. Students record their number, and use student_seed <- 1000 + seat_number. The lab uses a separate reproducible seed for each activity.
  2. Ask for a prediction before each single-simulation block. Students inspect the five lottery draws, the twenty shuffled temperatures, or the eight bootstrap draws before calculating a statistic.
  3. Each student reports ONE number to the whiteboard. Keep three separate labelled axes. Talk about the class distribution before students generate thousands of replicates.
  4. For a second round, use the supplied three-replicate blocks rather than repeatedly resetting the same seed. Re-running a block from its same seed intentionally reproduces the same results.
  5. Ask a student with an unusually high or low statistic to explain how their simulated dataset produced it. A shared statistic from different students is normal and does not mean their code failed.
  6. Finish with 10,000 simulations. Compare the smooth computer distribution with the rough whiteboard dots. Emphasize that simulation count changes Monte Carlo precision, while sample size changes information.

Suggested pause points: stop after my_sample and its mean, after one_shuffle and its mean difference, and after one_bootstrap and its mean. Each has a comment saying to report the statistic. Avoid sourcing the whole script during the first activity. The instructor can demonstrate the first block, but students run the single-simulation blocks themselves.

Opening language

“Geographers often want to understand a city, a population, or a process, but we observe only part of it. A sample gives an answer. Inference asks how much that answer might vary, and what conclusions the study design supports. Today we will use R to simulate the reference distributions that turn an observed number into an interpretable result.”

Benchmarks and expected discussion

  • Lottery population mean: 17.5 minutes. Its individual-observation SD is about 8.539 minutes. Theoretical SE at n = 5 is 3.819; at n = 20 it is 1.909. More observations reduce sample-mean variability under independence.
  • Shade mean: 33.6°C. Sun mean: 37.6°C. Observed difference: −4°C. Complete random assignment has 184,756 possible allocations. Exact two-sided randomization p = 0.024822. At a preselected .05 threshold this rejects the sharp no-effect null. Report the observed difference as well as the evidence. Random assignment supports the causal comparison for these experimental units under the design assumptions, not automatic statewide generalization.
  • A simulated p-value from 10,000 infer permutations should be near the exact value. infer doubles a tail for a two-sided p-value; direct absolute-tail counting may differ slightly in a finite simulation. Both target the same exact p here because this balanced design has a symmetric randomization distribution. Avoid changing tails after looking at the result.
  • Survey sample mean: 25 minutes. The independent Python illustration, with 50,000 resamples, gives an approximate percentile interval of 17.500–33.750 minutes. R’s seeded 10,000-resample output may differ slightly. This is an intentionally tiny, skewed teaching sample. Percentile-bootstrap coverage need not equal 95% here. A large resample count does not solve the information limits of n = 8.
  • The coverage figure uses a known-SD interval with new normal samples, specifically to illustrate the repeated-sampling definition without claiming that the eight-person bootstrap is exactly calibrated. The optional R coverage function uses genuinely new normal samples and bootstrap intervals, so its coverage is approximate and random.

Common answers and misconceptions

  1. One dot: a mean of five independent lottery draws; a mean difference under a possible null assignment; or a mean from an eight-row bootstrap resample. These represent different processes.
  2. Randomization without replacement: every observed plot outcome appears once, and both experimental groups retain n = 10. Bootstrap with replacement: repeated respondent rows allow resample composition to vary while preserving n = 8. Drawing all eight without replacement always returns mean 25.
  3. Correct p-value language: assuming no shade effect on any plot and the assignment model holds, the probability of a randomized mean difference at least 4°C from zero in either direction is about 0.025. This is not P(null is true) or the probability that the study’s conclusion is wrong.
  4. Correct confidence language: the interval estimates the city population mean. Its confidence level refers to the approximate coverage of the procedure over repeated original samples. It is not a range containing 95% of people and does not assign a frequentist probability to the fixed parameter after the interval is computed.
  5. Raising confidence from 90% to 99% widens the interval for the same bootstrap distribution. Raising resample count reduces Monte Carlo instability. Raising original sample size generally reduces SE under independent sampling, but cannot by itself repair bias.
  6. A p-value above .05 is insufficient evidence against the null at that threshold, not proof of no effect. A statistically significant difference need not be practically important. A small p-value does not establish good measurement, independence, or broad generalizability.
  7. Convenience samples and clustered/spatially correlated units require design-aware inference. Mention cluster or spatial block resampling as future material. Keep today’s simple iid survey and completely randomized experiment assumptions explicit.

Validation and limits

Arithmetic, exact randomization probability, bootstrap illustration, and sampling distributions were independently checked in Python. The HTML companion was built from the Quarto source through Pandoc with an offline presentation wrapper. This environment does not include R or Quarto, so the R code and native Quarto rendering have not been executed here. Function signatures and workflows were checked against official infer documentation. Run the R script once on your teaching computer before class. The source contains all figures inline and requires no external datasets or images.
